## Overview

This project compares two transfer-learning binary classifiers:

- **Model A:** MobileNetV2 trained on RGB images resized to 128 × 128.
- **Model B:** MobileNetV2 trained on images reconstructed from 32 × 32 to 128 × 128 by an SRGAN-style generator.

The SRGAN was trained for 150 epochs. Both classifiers were evaluated on the same held-out test partition.

## Preprocessing and transformations

The Pillow loader applies EXIF orientation correction, converts images to RGB, and resizes them to 128 × 128 using bicubic interpolation.

Classifier augmentation includes horizontal flipping, rotation, zoom, and contrast changes. MobileNetV2 preprocessing normalizes classifier inputs.

For SRGAN, high-resolution targets are normalized to [-1, 1]. Low-resolution inputs are created by bicubic downsampling to 32 × 32. Generated images are converted back to the classifier input range.

Examples of resized and transformed images are included in the notebook.

## Model A

Model A uses ImageNet-pretrained MobileNetV2 with its feature extractor frozen, followed by global average pooling, dropout of 0.2, and a sigmoid output.

The classifier uses binary cross-entropy and Adam with a learning rate of 0.001. The checkpoint with the lowest validation loss is selected.

The original Model A training history and epoch count were unavailable in the supplied notebook. Its restored optional training block specifies five epochs as a reproduction schedule; this is not a verified record of the original training duration. The saved Model A weights are used for the reported results.

## SRGAN

The generator contains eight residual blocks and two 2× PixelShuffle upsampling stages, producing 128 × 128 RGB images from 32 × 32 inputs.

The discriminator is a convolutional network that predicts real/fake logits. Generator loss combines pixel L1 loss, VGG19 perceptual loss, and adversarial loss:

`generator loss = pixel loss + 0.001 × perceptual loss + 0.001 × adversarial loss`

Both optimizers use Adam with a learning rate of 0.0001 and beta_1 of 0.9. The GAN batch size is 16.

Training reached 150 epochs. Checkpoints are saved every 10 epochs, allowing training to resume after a Colab disconnection. The checkpoint manager retains the five most recent checkpoints.

Restoration preserves the original checkpoint keys: `epoch`, `gen`, `disc`, `gopt`, and `dopt`.

This is an SRGAN-style implementation rather than an exact reproduction of every hyperparameter from the original SRGAN paper.

## Model B

Model B uses the same classifier architecture as Model A. Its inputs are generated by the frozen SRGAN from downsampled images in the corresponding fitting, validation, and test partitions.

Model B was trained for five epochs with a classifier batch size of 32. The checkpoint with the lowest validation loss was selected.

## Results

Both models were evaluated on 7,479 held-out test images. Classification uses a probability threshold of 0.5. F1 is calculated for the positive class, dogs; ROC-AUC uses predicted probabilities.

| Model | Accuracy | F1 | ROC-AUC |
|---|---:|---:|---:|
| Model A | 0.973392 | 0.973520 | 0.997085 |
| Model B | 0.936890 | 0.937134 | 0.984640 |

Model A correctly classified 7,280 images and misclassified 199. Model B correctly classified 7,007 images and misclassified 472.

Model A exceeded Model B by approximately 3.65 percentage points in accuracy and also achieved higher F1 and ROC-AUC.

Downsampling may remove information that super-resolution cannot fully reconstruct. Generated textures may also affect classification. These are possible explanations, not experimentally established causes.

The experiment compares original-resolution classification with SRGAN-based classification. It does not isolate the benefit of SRGAN against a separate low-resolution or bicubic-upsampled classifier baseline.

### Loading completed models

Leave these settings at their defaults:

```python
TRAIN_MODEL_A = False
TRAIN_SRGAN = False
TRAIN_MODEL_B = False
RUN_EVALUATION = False
```

This configuration loads saved classifiers, restores the epoch-150 GAN checkpoint, and reads saved metrics. Missing saved models cause an explicit error rather than automatic retraining.

The dataset is still required when executing the notebook from top to bottom. Saved outputs can be reviewed without executing any cells.

Set `RUN_EVALUATION = True` to recompute test metrics and plots. This overwrites the corresponding result files but does not train models.

### Optional retraining

To retrain, explicitly enable the relevant training switches and use a Colab GPU. ImageNet weight downloads require internet access.

SRGAN training resumes from the latest available checkpoint and targets 150 completed epochs. To reproduce training from scratch, use a separate output folder and enable all three training switches.

Exact retraining results may vary with library versions, hardware, and nondeterministic operations. Preserve the original saved models and split manifest as the reference for the reported results.
